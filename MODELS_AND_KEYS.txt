SatQuery AI — MODELS, DATASETS & API KEYS REFERENCE
=====================================================
Generated for the SIH 2026 submission. Every ID below is real and is
literally what's hardcoded in backend/app/config.py — nothing here is

------------------------------------------------------------------
1. API KEYS — I could NOT generate these for you. You must create
   your own (free tiers exist for both) and paste them into
   backend/.env (copy from backend/.env.example). Never commit .env.
------------------------------------------------------------------

GROQ_API_KEY=
  → Get one at: https://console.groq.com/keys
  → Used for: primary LLM orchestrator brain (query intent
    classification + tool routing + natural-language narration of
    specialist model outputs)
  → Model used: llama3-70b-8192  (env var: GROQ_MODEL, overridable)

OPENAI_API_KEY=
  → Get one at: https://platform.openai.com/api-keys
  → Used for: fallback LLM orchestrator brain if Groq is unset/fails
  → Model used: gpt-4o  (env var: OPENAI_MODEL, overridable)

LLM_PROVIDER_PRIORITY=auto
  → "auto" = use whichever key is present (Groq tried first), "groq"
    or "openai" to force one. If NEITHER key is set, the orchestrator
    still works — it falls back to real keyword-based intent
    classification (see backend/app/core/orchestrator.py), just
    without LLM-quality query understanding.

Nothing else in this project needs a key — Esri/NASA/OSM endpoints
below are public and keyless.

------------------------------------------------------------------
2. VISION / ML MODELS ACTUALLY WIRED IN THE CODE
------------------------------------------------------------------

VQA (BLIP-1)
  HF model ID : Salesforce/blip-vqa-base
  File        : backend/app/models/vqa_blip.py
  Library     : transformers.BlipProcessor / BlipForQuestionAnswering
  Status      : Real pretrained weights, works out of the box once
                downloaded (~1.5GB, needs internet on first run).

Land-cover classification (ResNet-50 / EuroSAT)
  Backbone ID : resnet50.a1_in1k  (via timm)
  Classes     : AnnualCrop, Forest, HerbaceousVegetation, Highway,
                Industrial, Pasture, PermanentCrop, Residential,
                River, SeaLake  (EuroSAT's 10 classes)
  File        : backend/app/models/landcover_resnet.py
  Status      : ImageNet backbone loads for real. Classification HEAD
                is untrained until you fine-tune it — run
                backend/train/train_eurosat_head.py on the real
                EuroSAT dataset and point EUROSAT_HEAD_WEIGHTS at the
                resulting checkpoint. Until then, honest classical-CV
                k-means clustering is used instead of a guessed label.

Change detection (MobileNet-V3 / LEVIR-CD)
  Backbone ID : mobilenetv3_large_100  (via timm)
  File        : backend/app/models/change_detection.py
  Status      : Same policy — backbone real, LEVIR-CD change head
                needs backend/train/train_change_head.py +
                CHANGE_HEAD_WEIGHTS. Fallback: classical LAB-space
                differencing + Otsu thresholding (real algorithm).

SAR + Optical fusion (Dual ResNet-18 / SEN12MS)
  Backbone ID : resnet18  (torchvision, two independent branches —
                one per modality)
  File        : backend/app/models/sar_fusion.py
  Status      : Backbones real, SEN12MS fusion head needs
                backend/train/train_sar_fusion_head.py +
                SAR_FUSION_HEAD_WEIGHTS. Fallback: classical SAR
                backscatter thresholding fused with an optical water
                heuristic (real signal processing).

Grounding / referring segmentation (SAM)
  Model type  : vit_b
  Checkpoint  : https://dl.fbaipublicfiles.com/segment_anything/sam_vit_b_01ec64.pth
  File        : backend/app/models/segmentation_sam.py
  Status      : Real Meta AI weights (~375MB, auto-downloads on first
                use if internet available). Fallback: classical
                HSV+morphology water mask / edge-density built-up
                mask.

LLM orchestrator (agentic tool router)
  File        : backend/app/core/llm_router.py, orchestrator.py
  Tools it can call: describe_image, change_trend, detect_change,
                fuse_optical_sar, ground_referring_expression
